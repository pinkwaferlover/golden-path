# Stuck work is never the green step

The green step means "safe to do right now, and git or GitHub proves it". Fixing a merge conflict or a failed check needs judgement, so a stuck pull request can never be green, even though it is the most urgent thing on the page. Instead, stuck pull requests appear in a banner above the board, and one button hands them all to Claude in a safe order (each one before anything built on it).

## Considered options

- **Stuck ranks first and the hand-off is the green button.** Rejected: green would then sometimes mean "safe" and sometimes mean "urgent but needs judgement".
- **A Stuck group just below the green step.** Rejected: it is easy to scroll past on a long board.
