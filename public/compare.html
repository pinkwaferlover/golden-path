With and without the bundle

Golden Path works on any git repo. The optional bundle adds a few habits to how you and your AI tools commit. The app then has more to tell you. Both panes below read the same repos, right now.

With the bundle

  • “Who made it” names the tool, model and task from the commit notes (Tool:, Model:, Task:).
  • Every session’s first push opens a draft pull request, so work in progress shows up early instead of hiding on one computer.
  • AI sessions end with a “Needs you” line linking here, from npm run summary.

Without the bundle

  • “Who made it” shows only the commit author and any Co-Authored-By line an AI tool added by itself.
  • Work shows up when someone happens to push or open a pull request.
  • Everything else — the journey, the recommendations, the reasons — works the same.
